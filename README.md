# netgig.online

Free hourly planner and productivity tools.

## Build

```
python build.py
```

Generates all pages into `docs/` from `pages-config.json` and `template.html`.

## Deploy

Push to main. GitHub Actions builds and deploys automatically.

## Kill Criteria

**LAUNCH DATE:** ___________

**DAY 30**
Affiliate program identified paying $20+ per conversion?
If NO, this is an ad-only site. Decide whether to continue.

**DAY 90**
Under 500 monthly impressions in GSC? KILL.

**DAY 120**
Under 2,000 monthly pageviews? KILL.

**DAY 150**
Under $30/month total revenue? KILL or park.
